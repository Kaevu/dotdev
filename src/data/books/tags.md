# Book Tags

Manually tag books by adding entries below in this format:

```
Clean Book Title | tag
```

A book can have multiple tags (comma-separated):

```
Dual Category Book | tag1, tag2
```

Valid tags: `cs`, `ml`, `finance`, `math`, `other`

Books not listed here will show as **untagged** in the bookshelf.
